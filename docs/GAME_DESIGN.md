# GAME DESIGN

## 1. 基本資訊
遊戲名稱：
親媽貓燁想奪走我的身體，殊不知我早已綁定系統了

專案名稱：
Lumi（暫定）

遊戲類型：
劇情探索式網頁解謎遊戲

平台：
Web Browser

部署：
GitHub Pages

主要裝置：
PC 優先、手機橫向支援

基準解析度：
1280 × 720

畫面比例：
16:9


## 2. 核心玩法

遊戲採混合式玩法：

- 定點場景探索
- 視覺小說式對話
- 對話選項
- 場景物件調查
- 記憶碎片收集
- 獨立解謎介面
- 特殊場景角色移動


## 3. 探索系統

玩家可以在部分場景中移動露米。

可調查物件會依場景提供：
- 劇情
- 線索
- 星光
- 記憶碎片
- 解謎資訊


## 4. 對話系統

使用角色半身立繪 + 底部對話框。

功能預計包含：
- 下一句
- 對話選項
- 對話紀錄
- 自動播放
- 跳過已讀


## 5. 解謎系統

主要解謎類型：
- 場景觀察
- 記憶碎片
- 靈魂節點
- 符文排列
- 線索組合


## 6. 任務系統

任務主要由600190號星光指引系統發布。

分為：
- 主線任務
- 新手任務
- 劇情任務


## 7. 存檔系統

第一版不使用後端。

使用：
- LocalStorage
- 自動存檔
- 手動存檔
- 多存檔欄位
- 匯出存檔
- 匯入存檔

存檔匯出格式：
.lumisave

存檔包含：
saveVersion


## 8. 美術規格

風格：
精緻 Pixel Art Fantasy

主題：
夢幻星空 × 黑暗童話

探索角色：
Pixel Sprite

劇情角色：
Pixel 半身立繪

UI：
現代高解析度 UI

系統介面：
半透明深藍 + 星光效果

中文字：
使用正常高解析度字體，不使用低解析像素中文字。
